- Ajout d'action de déclenchement globale (plus filtrée par zone, il est conseillé d'utiliser celle-ci plutot que les actions de déclenchement par zone)
- Optimisation du code
- ATTENTION : l'alarme n'execute plus les actions immediates si il n'y a pas de délai de déclenchement !!!!!!
