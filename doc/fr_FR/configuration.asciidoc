Sur la page du plugin, vide, il faudra ajouter une Alarme via le bouton +. Il est en effet possible d'avoir plusieurs alarmes, par exemple pour la maison et pour une dépendance... ou encore, pour l'alarme intrusion et l'alarme sécurité incendie...

image::../images/alarme2.png[]

Une fois créée, la page principale s'affiche pour la configuration de l'alarme. En haut l'onglet général, et en bas la configuration de l'alarme.

image::../images/alarme1.png[]

Dans la partie haute, onglet Général, il faut donner un nom à l'alarme et une appartenance dans l'arborescence. Il est possible de lui affecter une catégorie, puis de choisir de rendre actif ou visible l'alarme sur le dashboard.

image::../images/alarme3.png[]

Ensuite diverses options sont possibles. Comme par exemple activer l'alarme en permanence, ce sera le cas par exemple pour les détecteurs de fumées, monoxyde ou inondation... ou afficher sur le widget l'état de l'alarme (Armement, Libération, Statut).

image::../images/alarme4.png[]

En dessous se trouve la partie configuration de l'alarme avec plusieurs onglets. Le détail est présenté ci-dessous.

image::../images/alarme5.png[]

Le premier onglet est l'onglet Zone. Il permet de définir les zones de son alarme. Il est possible de définir autant de zones que souhaité. Ces zones peuvent être par exemple, le rez de chaussée, l'étage... Pour ajouter une zone, il suffit de cliquer sur le bouton vert "Ajouter zone".

image::../images/alarme6.png[]

Dans chaque zone plusieurs éléments peuvent être définis.

image::../images/alarme7.png[]

Pour cela il y a 3 boutons qui permettent d'ajouter des éléments dans chaque zone : les déclencheurs, les actions immédiates, et les actions.

image::../images/alarme8.png[]

Les déclencheurs : ce sont les éléments domotiques qui seront succeptibles de déclencher une alarme dans la zone définie. Comme par exemple un détecteur d'ouverture.
Pour chaque déclencheur vous pouvez définir un délai d'activation, qui permettra par exemple d'avoir le temps de sortir de la maison après avoir activé l'alarme à l'intérieur (typiquement une porte d'entrée).
Et à l'inverse, un délai de déclenchement qui permettra d'avoir le temps de désactiver l'alarme avant que celle ci sonne... Exemple : je rentre dans la maison par la porte d'entrée, la sirène ne se déclenche pas de suite pour me laisser le temps de désactiver l'alarme.

image::../images/alarme9.png[]

Les actions immédiates : ces actions seront lancées dès qu'un déclencheur sera actif pour cette zone sans tenir compte des délais (par exemple pour prévenir qu'on a oublié de fermer une fenêtre).

image::../images/alarme10.png[]

Les actions classiques : celles-ci seront à réaliser lorsqu'un des déclencheurs configurés pour la zone sera actif. Ces actions doivent tenir compte des délais précédemment configurés pour chaque déclencheur. (Ici lorsque je vais ouvrir la fenêtre cela va m'envoyer un SMS. On peut par exemple déclencher une sirène.)

Il est possible d'utiliser le tag : #trigger# dans les options des actions de type message pour que Jeedom vous précise le nom de la commande ayant déclenché l'alarme.

image::../images/alarme11.png[]

L'onglet "Mode" : permet de définir des modes à son alarme. Ce sont ces modes qui vont être activé dans l'alarme. Les modes sont un groupement de zones. Par exemple un mode "total" pour les zones Rdc+Etage, et un mode "partiel" pour la zone Etage

image::../images/alarme12.png[]

Pour ajouter un Mode : cliquez sur le bouton vert "Ajouter Mode". (Nommez le comme vous le souhaité)

image::../images/alarme14.png[]

Puis pour chaque mode, ajoutez autant de zones que nécessaire, via le bouton "+ Zone".

image::../images/alarme13.png[]

Ici que j'ai défini un mode "Total", avec dedans une zone "Etage".

image::../images/alarme15.png[]

L'onglet "RAZ".

image::../images/alarme16.png[]

Il permet simplement d'ajouter des actions lorsque l'alarme sera désactivée. Via les boutons "Ajouter Raz", les actions se produiront lorsque l'alarme aura été désactivée, par exemple désactiver la sirène. La particularité du bouton "Raz immédiat" est de rajouter des actions immédiates sur déclenchement, même si le déclenchement a un délai, par exemple pour signaler que l'alarme a détecté une intrusion sans faire sonner de suite la sirène.

image::../images/alarme17.png[]

L'onglet "Pertes de ping", permet de détecter des brouillages radio lorsque l'alarme est active.

image::../images/alarme19.png[]

Enfin, l'onglet "Activation OK" va permettre d'avoir des actions dès que l'alarme aura été activée, pour par exemple prévenir par SMS que l'alarme s'est bien activée.

image::../images/alarme22.png[]

Voici ce que donne le plugin alarme configuré simplement, sur le Dashboard. Le choix du mode, l'armement et la libération de l'alarme. A noter que sur une alarme active en permanence, il n'y a pas de bouton activer/désactiver pour la réinitialiser, il suffit de cliquer sur le mode en cours (ou autre). Attention la réinitialisation par clic sur le mode ne marche que pour les alarmes actives en permanence.

image::../images/alarme23.png[]

Ici le plugin alarme combiné avec le plugin SMS.

image::../images/alarme24.png[]

A noter, que pour toute la configuration, les déclencheurs et actions sont directement accessibles en cliquant sur le petit livre à côté du champ, qui donne une liste déroulante pour retrouver rapidement son équipement.

image::../images/alarme20.png[]

Ne pas oublier enfin, de sauvegarder une fois votre alarme configurée !
